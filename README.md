# 🤖 CV-shortlisting---AI

An AI-powered resume shortlisting system designed to assist HR professionals in efficiently filtering and selecting the most suitable candidates based on job descriptions and applicant resumes.

---

## 🚀 Project Overview

This tool leverages **Natural Language Processing (NLP)** and **Machine Learning** to compare resumes against a job description and return a ranked list of the best-matching candidates. It automates the manual screening process and speeds up hiring.

---

## ✨ Features

- 📥 Upload and parse multiple resumes  
- 📝 Match resumes with job descriptions  
- 📊 Rank candidates by relevance  
- ⚡ Fast, accurate, and AI-powered screening  

---

## 🛠️ Tech Stack

- 🐍 Python 3.x  
- 🧠 NLP (SpaCy / Transformers)  
- 📄 JSON for data handling  
- 🌐 Flask / FastAPI (optional API support)  

---

## 🧠 How It Works

1. HR uploads a **job description**  
2. System reads and parses **resume files**  
3. AI uses NLP to calculate **similarity scores**  
4. Outputs a **ranked list of top candidates**  

---

## 📌 Use Cases

- 👩‍💼 HR professionals and recruiters  
- 🏢 Companies processing large volumes of applicants  
- 🤖 Automated first-level screening in hiring pipelines
